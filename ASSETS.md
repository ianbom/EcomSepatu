## Reference inspection

Allbirds homepage, `/collections/new-arrivals-26`, and `/products/anytime-no-show-heel-grip` were inspected at 1440px and 390px using Chrome browser-harness. Recorded geometry: 32px desktop announcement; floating 48px navigation; narrow page gutters; split desktop hero; four category tiles; four/two-column desktop/mobile collection grid; desktop two-column sock gallery and right information panel; mobile title above gallery; Fit Guide; accordion content; lower editorial and footer blocks.

The live collection has substantially more than 18 entries and contained placeholder text during inspection. This implementation uses the requested 18-item catalog and original copy instead. Unrendered/empty reference sections are not invented. No real cart modification or checkout was performed on the reference website.
